BRENDO — English-only responsive website

This edition removes the language switcher and all multilingual translation dictionaries.
The site is English-only.

Mobile enhancements include responsive hero and product imagery, mobile navigation,
refined spacing and typography, responsive product goal cards, packaging gallery,
and a new origin / product-transparency section.

Country of origin: Thailand, based on the information supplied by the customer.
Authenticity wording is deliberately transparent: no independent authentication,
manufacturer identity, regulatory approval, GMP certificate or laboratory test is claimed.
For a genuine authenticity claim, add verifiable manufacturer/importer documents,
batch/lot traceability, and an official verification channel such as a working QR code.

Files: index.html, styles.css, script.js, assets/
Open index.html in a modern browser. Google Fonts may require an internet connection.
